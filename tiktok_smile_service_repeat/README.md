# BARH · SMILE SERVICE REPEAT — вертикальный ролик для TikTok

Готовый монтаж, оригинальный звук, сториборд и тренд-бриф для картины «SMILE SERVICE REPEAT».
Видео собирается **только из исходного холста** (`artwork.jpg`): никакой генеративной графики,
только камера, типографика и синтезированный с нуля звук.

## Быстрый старт

```bash
cd /home/user/image_gallery
python3 -m venv .venv
.venv/bin/pip install -r tiktok_smile_service_repeat/requirements.txt
cd tiktok_smile_service_repeat
../.venv/bin/python build_video.py        # ~2.5 мин, сам вызовет make_audio.py при необходимости
```

Нужны: Python 3.10+, `numpy`, `opencv-python-headless`, `scipy`, `imageio-ffmpeg` (внутри лежит
собственный бинарник ffmpeg), `Pillow`. Отдельно устанавливать ffmpeg в систему не нужно.

## A/B-тест хука за 2.5 минуты

В начале `build_video.py` лежат четыре константы — больше ничего трогать не надо:

```python
HOOK = ['УЛЫБКА —', 'ЧАСТЬ ФОРМЫ']
HOOK_SUB = 'НО ПОСЛЕ СМЕНЫ ЕЁ НЕ СНЯТЬ'
WORDS = [('SMILE', 'УЛЫБНИСЬ'), ('SERVICE', 'ОБСЛУЖИ'), ('REPEAT', 'ПОВТОРИ')]
COMMENT_BAIT = 'УЗНАЁШЬ СВОЮ СМЕНУ?'
```

Пять готовых вариантов хука — в `STRATEGY.md`, §6. Меняете `HOOK`/`HOOK_SUB` → запускаете
`build_video.py` → получаете новый ролик с той же музыкой и таймингом. Сравнивать нужно
**удержание на 3-й секунде**, а не лайки.

## Подмена музыки

* **Своя фонограмма:** положите любой WAV/MP3 вместо `audio/BARH_original_sound.wav`
  (или правкой `AUDIO` в `build_video.py`) и пересоберите — скрипт не перезапишет существующий файл.
* **Трендовый звук из TikTok:** берите `SMILE_SERVICE_REPEAT_BARH_silent.mp4`, в редакторе TikTok
  добавьте звук и подрежьте его так, чтобы сильная доля пришлась на **2.727 с** (там у нас дроп и
  первая команда SMILE). Полная карта битов — в `STRATEGY.md`, §4.
* Если меняете темп: `BPM` должен быть одинаковым в `make_audio.py` и `build_video.py` — от него
  считается и длительность, и все склейки.

## Устройство монтажа

* `camera(t)` задаёт «видимую высоту холста» и центр кадра; всё движение — плавное, склейки жёсткие
  и лежат ровно на границах тактов. Эффекты: вспышки, зум-панч на доле, RGB-глитч на `REPEAT`,
  whip-pan, зерно, виньетка.
* `text_layer(t)` — кинетическая типографика. Плитки строк кешируются, поэтому 654 кадра
  рендерятся без перерисовки глифов.
* **Безопасная зона TikTok:** весь смысловой текст выше y≈1600 и левее x≈900 — не под подписью и
  не под кнопками справа. Если добавляете свои строки, держитесь этой области.
* **Петля:** кадр 18.8 с повторяет кадр хука 1.2 с, а чёрный финал с логотипом смыкается с чёрным
  стартом. Не обрезайте ролик в приложении — сломаете loop.
* SERVICE-кадр построен как контекстный (крылышко, рука, тележка). Для ещё более консервативной
  версии под рекламу сдвиньте `cx` на +150, `cy` на +250 в ветке `camera()` с комментарием
  `SERVICE` — в кадре останутся только атрибуты сервиса.

## Шрифты и лицензии

Шрифты получены из репозитория `google/fonts` и распространяются по SIL Open Font License 1.1:
`fonts/OFL-Anton.txt`, `fonts/OFL-Oswald.txt`, `fonts/OFL-IBMPlexMono.txt`.
Anton — латиница (логотип, английские слова), Oswald Variable 700 и IBM Plex Mono Bold — кириллица.

Звук `audio/BARH_original_sound.wav` синтезирован программно, не содержит сэмплов, чужих
фонограмм или мелодий; принадлежит проекту и безопасен для коммерческого использования.
Права на изображение картины принадлежат автору BARH.
