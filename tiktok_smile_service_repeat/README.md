# BARH — «SMILE SERVICE REPEAT» (TikTok 9:16)

Финальный двуязычный (EN + RU) вертикальный ролик `1080×1920`, `30 fps`, `22.18 с` (`−13.1 LUFS`) с камерным ночным синтезаторным ноктюрном в духе **Space — «Secret Dreams» (1978)** (`audio/BARH_secret_dreams_60bpm.wav`) для картины **`SMILE SERVICE REPEAT` / «Повтор службы улыбок»** (`46 × 130 см`, холст, масло).

## Итоговый файл
- **`SMILE_SERVICE_REPEAT_BARH.mp4`** (`9.9 МБ`):
  - `0.00 – 4.25 с`: Ночной пентхаус с крупной двуязычной надписью поперёк экрана (`Stop. Deep breath. Relax and look.` / `Остановись. Глубокий вдох. Расслабься и посмотри.`).

  - `11.15 – 15.65 с`: Чистая дневная современная резиденция (без мелких подписей) с живым солнечным лучом.
  - `15.65 – 19.95 с`: Единый плавный проезд по всей ширине картины сверху донизу (`1384 → 1080`, без рывков и сильных приближений).
  - `19.95 – 22.18 с`: Финал — крупный фирменный рукописный белый логотип `BARH` на `#000000`.
