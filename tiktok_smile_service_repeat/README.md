# BARH — «SMILE SERVICE REPEAT» (TikTok 9:16)

## Итоговый файл
- **`SMILE_SERVICE_REPEAT_BARH.mp4`** (`9.9 МБ`):
  - `0.00 – 4.40 с`: Ночной пентхаус (`01 · TWILIGHT PENTHOUSE`) + крупный двуязычный старт `Stop. Deep breath. Relax and look.` / `Остановись. Глубокий вдох. Расслабься и посмотри.`

  - `11.10 – 15.55 с`: Дневная современная резиденция (`02 · DAYLIGHT RESIDENCE`) с живым солнечным лучом.
  - `15.55 – 19.90 с`: Единый плавный проезд по всей ширине картины сверху донизу (`1384 → 1080`, без рывков и сильных приближений).
  - `19.90 – 22.11 с`: Финал — крупный фирменный рукописный белый логотип `BARH` на `#000000`.
